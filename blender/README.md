# 可编辑 Blender 模型

下载 [small-goods-harbor.blend.zip](small-goods-harbor.blend.zip)，解压后直接打开根目录中的 `small-goods-harbor.blend`。归档还包含 `manifest.json` 和 `FONT_NOTICES.txt`。

模型来自与网页 GLB 对应的场景快照，独立保存；未修改原场景或合并主项目。使用 Blender 5.2.0 LTS 完成保存与后台重开验证。

## 保留内容与验证

- 场景：`Small Goods · Reference Harbor`；2962 个对象、66 种场景材质、2 台相机、9 盏灯及四朵可见云。
- 原始可编辑几何、曲线/文字、材质节点、修改器、相机与灯光完整保留；未使用网页精简网格替代源模型。
- 469 条驱动有效，水面形态键完整保留。24 fps、帧 1–144，六秒循环；第 145 帧回到第 1 帧相位。
- 已在独立 Blender 进程中真正重新打开最终文件，比较几何、材质节点图和驱动指纹，结果一致。帧 1、37、145 的水面及小船采样与源快照一致；未进行额外离线渲染。

## 可移植性与隐私处理

只携带小岛场景及其依赖，去掉无关启动场景、原编辑器布局状态、无关画笔资源引用、本地预览/参考文件引用和旧审计备注。渲染输出改为 `//renders/harbor-`；字体引用改为 `//fonts/georgia.ttf`，字体数据已内嵌，无需另行寻找该路径。

清理了保存的文件浏览目录，并清零固定字符串缓冲区中已无效的旧目录尾部。检查了资源引用、自定义属性、Text 脚本和未压缩模型字节；所检查的个人路径、工作目录标识及常见令牌模式均为零匹配。源文件路径和私人审计日志未放入归档。

资源枚举没有外部贴图文件或链接库依赖。原生程序化材质和字体保存在模型中；无内嵌 Text 脚本。水面、小船和水下光纹通过保留的原生驱动运行，不依赖 MCP 服务。

内嵌字体为 **Georgia Regular 5.59**，字体元数据标识 Matthew Carter / Carter & Cone，版权为 Microsoft。其 `fsType=8` 表示可编辑嵌入；保留完整字体版权和许可声明，见 [FONT_NOTICES.txt](FONT_NOTICES.txt)。没有单独分发字体文件。

## 本地运行

网站采用原生 HTML、CSS、JavaScript 和 Three.js，运行依赖已经随仓库提供，**无需安装 npm 依赖，也无需构建**。

在 Windows 上，安装 Python 3 后，可以直接双击仓库根目录的 [启动小岛网站.cmd](启动小岛网站.cmd)。它会启动仅供本机访问的服务并打开默认浏览器；再次双击会复用已运行的服务。默认使用 5207 端口，占用时会尝试 5198 或其他空闲端口。它读取当前文件夹里的 `dist/`，不会自动执行 `git pull` 或切换 Git 版本。关闭浏览器不会停止后台服务，重启电脑后需要再次双击启动。

1. 获取本仓库的完整文件。
2. 安装 Python 3，在仓库根目录运行以下命令。
3. 在浏览器打开 <http://127.0.0.1:5198/>。

Windows：

```powershell
py -m http.server 5198 --bind 127.0.0.1 --directory dist
```

macOS / Linux：

```bash
python3 -m http.server 5198 --bind 127.0.0.1 --directory dist
```

终端按 `Ctrl+C` 停止。如果端口被占用，将命令和地址中的 `5198` 改为其他空闲端口。请通过 HTTP 服务器访问，不要直接双击 `index.html`。

浏览器需要支持 **WebGL 2、ES Modules / importmap、Web Worker 和 WebAssembly**。默认 GLB 约 7.24 MB，首次打开还会加载本地打包的 JavaScript 和解码器；7.24 MB 并非整页总下载量。环境声音仅在点击开关后加载。

## 模型与动画实现

| 资源 | 大小（十进制） | 三角面数 | 用途 |
| --- | ---: | ---: | --- |
| `harbor-lite.glb` | 7.24 MB（7,242,152 字节） | 603,071 | 默认网页模型 |
| `harbor.glb` | 11.59 MB（11,589,740 字节） | 1,147,513 | 高细节备用资源 |

界面提供清晰、精细和流畅三档画质，使用同一模型。清晰档按屏幕像素密度渲染，普通屏幕为 1 倍，高 DPR 设备最高 2 倍；精细档最高 2.5 倍。各档还受画布像素预算约束，不低于 CSS 尺寸的 1 倍，不会因一次慢帧永久降画质。当前加载逻辑通常使用精简模型，仅在精简元数据请求返回非成功 HTTP 状态时尝试备用资源；它不是覆盖所有下载或解码错误的自动回退机制。

两个主岛 GLB 都使用 Draco 压缩，解码器已本地打包。模型颜色主要保存在顶点色中。29 种材质使用内嵌微法线与粗糙度纹理，涵盖木材、砂、岩石、土层和织物；共 10 张 PNG，均在 GLB 内，无需外部图片。GLB 本身没有动画片段；海浪、岸边泡沫、水下光纹和小船运动由 `water.js` / `viewer.js` 实时实现。背景微浪保留六秒周期；交互波浪由 water-physics.js 实时模拟传播、反射与阻尼。harbor-motion.js / harbor-navigation.js 驱动小船导航、浮动、人物与小狗行走，整体不再固定六秒循环。阴影最多每秒更新 10 次，默认阴影贴图仍为 1536；水下光纹由预计算纹理驱动，减少每帧着色负担。

网页顶面采用相对平静水面的波纹微折射，偏移最多 2.25 个实际画布像素，并拒绝线性深度跳变达到 0.12 的候选点、在深度梯度处渐弱；最终颜色、深度和吸收光程使用同一有效采样。侧面采样原位置景物、按统一光学厚度 1.50 计算吸收的切面透光，移除纵向颜色与透明度渐变和额外清漆反光。侧面用保留亮度的 60% 共享水色混合减少偏绿边圈，顶面外缘 0.70 场景单位渐变衔接到同一切面效果；这属于展示近似，避免再作为一层玻璃强折射，不是完整物理体积追踪。干地保护、内圈岸线遮罩与折射候选点的水域检查继续保留，外圈水壁保持完整。水下石头和木桩会随水面法线产生可见偏移；柔和天空反射与较低对比的水下光纹共同表现透明度。屏幕空间方法无法还原画面外或被遮挡的物体，也不是 Blender Cycles 的完整光线追踪。水的运动仍是有边界的二维高度场近似，不是完整三维流体。

水下新增 9 处小型群落，共 114 块碎石、63 株海草和 3 群 / 24 条鱼，以 6 个实例化网格绘制。砂床与切缘统一为灰米色。当前水体半径为 9.0、深度为 1.80，与底座基本齐平；网页加载时克隆 5 个海床 / 地层网格，将上缘最大半径从约 9.0305 内收到 8.925，水底交接截面没有突出水壁，下部地层保持原样。三群鱼分别沿长度约 45.05、46.74、48.39 的整岛路线巡游，速度为 0.50、0.555、0.61 场景单位/秒，并交错顺逆方向；实际模型 180 秒检查未发现鱼身、水域或海床违规采样。小船沿半径 7.8、长度约 49.01 的闭环连续巡航，96 个路点按固定方向衔接，实际速度约 0.765 场景单位/秒，约 64 秒一圈（首次出港另计）；整船姿态安全检查继续保留。三名陆地居民与小狗在实际沙地生成的导航网格上选择较远目标、停步并绕开静态障碍；码头工人仍在码头活动。

V11 点击水面使用强度 2.2、足迹 0.60 的不对称椭圆凹陷，再由高度场产生回弹与传播，单击峰值约 0.194，约为旧值 0.063 的三倍；背景微浪保持不变。已删除小船点击目标的 Torus 圆环，点击引航仍保留。30 秒连续输入检查没有非有限数，平均水位漂移保持在数值误差范围内。

V7–V13 的材质、水下细节、光学与漫游改动主要来自网页运行时代码。此后 V14.1–V14.3.1 也更新了 Blender 场景和 GLB；当前的 `small-goods-harbor-pov.blend.zip` 已包含最新模型修复。角色路线、视角跟随和环境声音仍由网页 JavaScript 实现。

## 验证与依赖许可

V13 小船在 Node 240 秒模拟中绕行约 3.735 圈，受阻和不安全采样均为 0；实际 GLB 浏览器按固定步长加速推进 135 秒模拟时间，结合水面、浮力与尾迹完成两整圈，受阻、不安全采样和页面错误均为 0。135 秒是模拟时间，不是等待同等时长的实时播放。另经 5 组各 180 秒点击模拟，4 个有效目标到达并短暂停留后恢复巡航，越界目标被拒绝；全部受阻 / 不安全采样为 0。实际 GLB 浏览器也通过 180 秒模拟的点击到达 / 恢复巡航检查。

# Blender 场景与 MCP 工作流

本仓库同时提供可直接运行的网页和可继续编辑的 Blender 场景。两者来自同一版场景快照，采用不同的渲染与动画实现。

## 打开模型

下载 [Blender 场景压缩包](../blender/small-goods-harbor.blend.zip)，解压后在 Blender 中通过「文件 → 打开」选择 `small-goods-harbor.blend`。主场景名为 `Small Goods · Reference Harbor`。制作环境为 **Blender 5.2.0 LTS**；建议使用同版本打开，其他版本尚未逐一验证。

打开、编辑和渲染这个模型均不需要 MCP，也不需要连接网页服务器。

场景保留了岛屿地形、岩石与植被、商店、码头、小船、人物、四朵云，以及材质、灯光和相机。可在三维视图中旋转查看，或切换相机视图检查构图。材质与透明水效果请用渲染预览查看；按 `F12` 可生成当前帧的渲染图。实体显示模式不会展示完整水体效果。

## 播放动画

时间轴范围为 **1—144 帧、24 fps，循环时长为 6 秒**。点击时间轴的播放按钮，可以查看水面起伏、岸边浪花、小船轻晃以及随时间变化的水底光纹。

水面通过形状键与驱动器变形，水体底部保持固定；小船有轻微上下运动与摇摆。细浪高光和水底焦散使用程序化效果。这些是为微缩场景设计的循环动画，没有进行完整流体模拟或船只浮力求解。

## Blender MCP 是什么

Blender MCP 用来把 AI 客户端与正在运行的 Blender 连接起来。自然语言要求由 AI 转为场景操作或 Blender Python 代码，插件在 Blender 内执行，再返回检查结果。相关上游是作者维护的社区项目 [MCP for Blender](https://github.com/ahujasid/mcp-for-blender)，并非 Blender Foundation 官方插件。

本场景的实际制作流程是：

1. 检查正在打开的场景，保存修改前的备份。
2. 按局部任务生成 Python 操作，例如调整山脚、材质、灯光或云的位置。
3. 通过 Blender 插件执行，再读取对象和动画状态。
4. 渲染正面、背面或侧面，检查结果后继续微调并保存。

制作过程中也使用了一个本地 Python 桥接脚本：连接本机 `127.0.0.1:9876`，发送包含 `type: "execute_code"` 与 `params.code` 的 JSON 请求，由插件调用 Blender Python 执行并返回 JSON 结果。这是插件的本地 socket 通信层；它与 AI 客户端所使用的 MCP 协议层是两个环节。

## 可选：继续用 MCP 修改

如果希望通过自然语言继续修改模型，可按作者仓库的 [安装与连接说明](https://github.com/ahujasid/mcp-for-blender#quickstart) 配置。流程包括安装并启用 Blender 插件、为所用 AI 客户端配置 MCP 服务，以及确认 Blender 侧连接已启动。具体客户端配置与按钮名称以该版本上游文档为准。

服务只在本机使用，不要把 Blender 执行接口开放到公网。首次连接先进行只读检查，例如读取场景名称、对象数量和动画范围；确认连接到目标场景后，再让 AI 修改副本。插件能够执行 Python，修改前保留备份，并检查要执行的操作。

例如，可以提出以下要求：

- 「先检查当前场景，不修改任何对象，告诉我相机和动画范围。」
- 「将后山附近的小云稍微抬高，保持中央最大云的位置不变。」
- 「微调暖色主光，保持沙滩细节，并渲染一张预览给我检查。」

这些操作需要自行配置的 MCP 客户端与插件。模型压缩包不附带个人客户端配置、凭据或本机桥接脚本，也不要求重放历史建模脚本才能打开完成场景。

## 与网页版本的区别

| 内容 | Blender 场景 | 网页展示 |
| --- | --- | --- |
| 几何 | 保留可编辑对象与场景结构 | 使用导出的 GLB，并针对实时显示简化、压缩 |
| 材质 | 程序化节点、灯光与 Cycles 渲染 | GLB 顶点色配合 JavaScript 着色器补充木纹、沙粒和岩石细节 |
| 水与动画 | 形状键、驱动器与程序化材质 | `viewer.js`、`water.js` 实时生成波浪、光纹、泡沫与船体运动 |
| 光照与透明效果 | 由 Blender 渲染器计算 | 以实时性能为目标的近似；默认水体没有开启物理透射 |
| 预览图 | Blender 离线渲染 | 浏览器实际显示截图 |

GLB 本身不含动画轨道，也不依赖外部图片纹理；网页动画由上述 JavaScript 代码实现。因此，把 GLB 单独放进其他查看器，并不会自动获得网页中的动态海水。

README 中标注为网页效果的截图展示的是浏览器画面，不能当作 Cycles 原始渲染图。编辑并保存 `.blend` 也不会自动更新网站：需要重新导出模型，并根据变化同步网页中的材质或动画实现。
